# 恐龙突围：战术联动

这是一个无需安装依赖的静态网页小游戏，直接打开 `index.html` 即可试玩。

## 玩法

- 单人王牌：掌控当前选中的一名队员。
- 全员协作：使用 `L` 切换队员，`SPACE` 释放全员合击。
- 鼠标点击画布移动，按住画布下方左右箭头连续移动；点击跳跃、攻击、绝技按钮执行动作。
- 地面与空中均可战斗：长按跳跃按钮（或 `W`）会进入悬停空战状态，松开后缓慢落地。
- 战斗内置实时声效：攻击、命中、跳跃、拾取、受击、合击、通关和失败都有不同反馈；右上角 ♫ 可静音。
- 键盘快捷键仍保留：`A / D` 移动，`W` 跳跃，`J` 普攻，`K` 释放金庸招式。
- 战斗中随机出现能量包、血包、飞侠导弹和冰晶护盾。
- 五个场景都可以在任务板直接选择：沙漠、雨林、大海、雪山、时空遗迹，难度逐步提升。

## 发布分享

把整个文件夹上传到 GitHub Pages、Vercel、Netlify 等静态托管服务后，点击页面右上角“分享试玩”，即可复制带关卡和模式参数的链接，例如：

`https://你的域名.example/#mission=3&mode=squad`

这是纯前端版本，不需要服务器接口或数据库。
